# Чемпионат Only - HTML Academy

Проект выполнен на основе макета digital-агентства [Only](https://only.digital/), по мотивам чемпионата, проведенного компанией [HTML Academy](https://htmlacademy.ru/).

## Стек

HTML, CSS (SASS), Javascript (чистый JS без использования фреймворков и библиотек - в соответствии с требованиями чемпионата)

## Запуск

Для сборки необходимо наличие Node.js версии 22

- Установка всех зависимостей:

```
npm ci
```

- Запуск версии для разработки:

```
npm start
```

- Сборка продакшн-версии:

```
npm run build
```

- Линтинг:

```
npm run lint
```
